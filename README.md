# Qube

An interactive, responsive web experience built with modern web technologies, fluid animations, interactive 3D WebGL graphics, and touch gesture support.

## Overview
- **3D Graphics:** WebGL particle and geometric visual effects
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports
- **Audio:** Web Audio API sound synthesis
- **Components:** Interactive cards, touch-enabled modals, and fluid animations
- **Architecture:** Zero-build single-file static delivery

## Getting Started
Open `index.html` directly in any modern browser, or run a local static server:
```bash
python -m http.server 8000
```
